# Business & Operations Analyst Journey: a 16-week self-study programme

A structured, project-based programme to become a **Business / Data Analyst** or **Operations Analyst**, with AI used throughout.
Every chapter, assignment and project in this repository is part of one learning path. The work is done in public as a portfolio.

> **About the projects:** All projects use **RainCraft Umbrellas Pvt. Ltd.**, a *fictional* umbrella manufacturer-distributor. Its data is simulated by the script in [`datasets/`](datasets/). The business problems inside the data are realistic. The company and the numbers are not.

---

## What this programme covers

| Track | What I build |
|---|---|
| **Business thinking** | How companies run (order-to-cash, procure-to-pay), P&L, cash flow, working capital, inventory, strategy frameworks, structured problem solving |
| **Excel** | Formulas, Tables, lookups, data cleaning, Pivot Tables, dashboards, Power Query |
| **SQL** | MySQL: querying, joins, CTEs, window functions on a 3-year, 300k-row dataset |
| **Power BI** | Data modelling, DAX, interactive operations dashboards |
| **Statistics** | Descriptive statistics, distributions, A/B testing intuition, forecasting basics |
| **Business Analysis** | Requirements, stakeholder mapping, user stories, Agile/Scrum, Jira |
| **AI for analysts** | Prompting, verifying AI output, AI inside Excel/Power BI, workflow automation, building a small AI agent |
| **Communication** | Professional email, executive summaries, data storytelling, presentations |

## Weekly rhythm

| Day | What happens |
|---|---|
| Days 1–5 | Learn a topic → watch 1–3 short videos → do the daily assignment → solve the Case of the Day → 10 minutes of English practice |
| Day 6 | Weekly case study (2 hours, on RainCraft data) |
| Day 7 | Review quiz, GitHub update, LinkedIn post, weekly check-in |
| Every 3rd week | Capstone project (portfolio piece) |
